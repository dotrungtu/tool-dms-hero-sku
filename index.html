Bước 2 — Thiết lập cho đợt tạo file lần này

Những thông tin này không có trong file Excel đầu vào nên cần bạn nhập mỗi lần tạo file mới.
Sẽ ghép vào trước mã, ví dụ: 260801DNC01_CF_A

Cách xử lý sản phẩm hết tồn kho

Tồn kho cộng dồn theo từng Area, lấy từ cột Stock Available trong INVT_MASTER.csv (hoặc cột AVAILABLE_STK nếu dùng Stock Area.xlsx).

Lưu ý: DMS chỉ cộng dồn khi upload, không xoá được SKU đã đưa lên. Danh sách chốt đầu tháng chỉ có thể tăng thêm, không thể bớt đi cho tới khi hết hạn.
Đang đọc thông tin đợt từ file mốc...

Ở chế độ cập nhật, mã MSL và ngày hiệu lực được giữ nguyên theo đợt đang chạy — không nhập tay, để tránh việc DMS tạo ra danh sách mới thay vì cập nhật danh sách hiện có.

Quy tắc an toàn: vì DMS cộng dồn khi upload, công cụ chỉ sinh ra phần cần thêm. File CONDITION và CUSTASSIGN chỉ chứa danh sách mới phát sinh — nếu upload lại chúng cho danh sách đang chạy sẽ bị nhân đôi dòng.

Bước 3 — Bổ sung dữ liệu còn thiếu

Công cụ phát hiện một số dữ liệu chưa có trong bảng tra cứu. Vui lòng nhập bổ sung, hoặc tick «Bỏ qua» nếu muốn loại phần đó khỏi file xuất ra. Thông tin bạn nhập sẽ được ghi nhớ cho các lần chạy sau trên máy này.

① Area chưa có mã nhà phân phối (dòng cấp G trong CUSTASSIGN)

② Loại cửa hàng chưa rõ cách gán nhóm khách hàng

③ SKU Groups chưa tìm được Item Code trong Product List

④ Nhà phân phối mới trong INVT_MASTER chưa có Region / Area

Nhập Region và Area cho NPP mới, hoặc tick «Đã ngưng kinh doanh» để bỏ qua toàn bộ tồn kho của họ.

Bước 5 — Tải file kết quả

Hoàn tất! Bấm «Tải tất cả» để lấy đủ 4 file CSV upload lên DMS, hoặc tải riêng từng file.
Thứ tự upload: tải MSL_INFO_UPDATE.csv trước, rồi MSL_CONDITION_NEW.csv và MSL_CUSTASSIGN_NEW.CSV, cuối cùng là MSL_PRDASSIGN_ADD.csv. File nào có 0 dòng thì bỏ qua, không cần upload. Các file MOC_MSL_*.csv không upload.

File phân tích & đối chiếu

Dùng để gửi lại Biz Team hoặc rà soát trước khi chốt danh sách.

Bộ file mốc cho lần cập nhật sau

Không upload các file MOC_MSL_*.csv lên DMS. Đây là trạng thái DMS sau khi upload xong các file phía trên (file mốc lần này + phần bổ sung, đã gộp sẵn). Lần cập nhật sau, tải 3 file này vào ô «File của lần upload gần nhất» ở Bước 1. Nút «Tải tất cả file» cũng tải kèm 3 file này.
Chưa upload được file nào thì không dùng bộ file này — dùng lại bộ file mốc cũ. Đã upload được một phần (VD: lỗi ở MSL_PRDASSIGN_ADD.csv) thì sửa và upload lại cho đủ các file còn lại, rồi mới dùng bộ file mốc mới — dùng lại bộ cũ sẽ làm công cụ xuất lại danh sách đã lên DMS và nhân đôi dòng.
